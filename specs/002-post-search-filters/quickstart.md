# Quickstart: Фильтры-уточнения (Post-Search Refinement Chips)

**Feature**: 002-post-search-filters | **Date**: 2026-02-08

## Prerequisites

- Node.js 20+
- Backend running on `http://localhost:3002` (or Docker)
- Frontend dev server

## Setup

```bash
cd frontend
npm install   # no new dependencies needed
npm run dev   # http://localhost:3003
```

## Testing Scenarios

### 1. Happy Path — Фильтрация по одному параметру

1. Открыть `http://localhost:3003`
2. Ввести запрос: "авто до 3 млн" (широкий запрос для разнообразных результатов)
3. Дождаться результатов
4. **Проверить**: над карточками появились чипсы-фильтры, сгруппированные по категориям
5. Кликнуть на чипс (например, "дизель")
6. **Проверить**: список сузился, счётчик обновился, чипс выделен
7. Кликнуть на активный чипс ещё раз
8. **Проверить**: фильтр снялся, показаны все результаты

### 2. Комбинирование фильтров

1. Выполнить поиск с широкими результатами
2. Выбрать "дизель" в группе двигатель
3. Выбрать "АКПП" в группе КПП
4. **Проверить**: остались только дизельные АКПП, счётчики обновились
5. Выбрать "бензин" в группе двигатель (добавить к "дизель")
6. **Проверить**: показаны дизель ИЛИ бензин, С АКПП

### 3. Сброс фильтров

1. Применить 2-3 фильтра
2. Нажать "Сбросить фильтры"
3. **Проверить**: все фильтры сняты, показаны все результаты

### 4. Новый поиск сбрасывает фильтры

1. Применить фильтры
2. Выполнить новый поиск
3. **Проверить**: фильтры сброшены, чипсы сгенерированы из новых результатов

### 5. Edge Case — Скрытие однозначных групп

1. Выполнить запрос "бмв x5 дизель" (все результаты дизельные)
2. **Проверить**: группа "Двигатель" НЕ отображается (нечего фильтровать)

### 6. Edge Case — Disabled чипсы

1. Выполнить широкий поиск
2. Применить комбинацию фильтров, при которой некоторые значения дают 0 результатов
3. **Проверить**: чипсы с (0) видны, но некликабельны (disabled)

### 7. Edge Case — "Показать ещё" с фильтрами

1. Выполнить поиск, применить фильтр
2. Нажать "Показать ещё"
3. **Проверить**: новые авто также фильтруются, чипсы пересчитаны

## No Backend Changes

Эта фича не требует изменений бекенда. Все данные для фильтрации (`engine_type`, `transmission`, `drive_type`, `body_type`, `year`) уже присутствуют в ответе API `/api/v1/parse`.
